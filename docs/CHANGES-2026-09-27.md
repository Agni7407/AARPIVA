# AARPIVA V1 – latest fixes

- Home category cards now use explicit Angular navigation to the selected category in Shop.
- Product-card Add to Bag buttons are normal-flow buttons below product information instead of floating overlays.
- Shop price filters are functional and use backend min/max price filtering, including demo-product fallback filtering.
- Checkout now loads saved addresses with refresh/error feedback and handles address-save errors without losing the form state.
- Authentication now detects expired JWTs and the interceptor redirects 401 sessions back to login.
- Admin dashboard now has functional overview cards, recent orders, refresh/retry actions, and tab-level data reloads for orders/customers.
- Responsive layouts were tightened for home, shop, checkout, cart, product details, authentication, and admin screens.
- Existing demo-product and Razorpay functionality has been preserved.

### 2026-09-27 address + admin order fixes
- Admin order list now includes purchased items and shipping address details.
- Order status values are serialized/deserialized as strings so admin status changes work.
- Customers can edit/delete saved addresses and newly added addresses appear immediately without refresh.
- Address form now reliably exits saving state on success/error and selects the saved address.
