# Product images stored in the repository

Place product images in this folder and use an absolute browser path in the admin product form:

/assets/products/your-image.jpg

Example:

1. Put `red-banarasi.jpg` in `src/assets/products/`.
2. In Admin > Products > Product image, enter `/assets/products/red-banarasi.jpg`.
3. Save the product.

Cloudflare R2/CDN URLs can be used in exactly the same field when the CDN is configured.
